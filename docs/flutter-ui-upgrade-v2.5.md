# 剧立方 DramaCube Flutter 版 — UI 升级 + 交互升级设计文档

> 版本：v2.5 设计提案 · 2026-10-12
> 范围：Flutter 全平台（Android 手机 / 平板 / Windows / Linux / macOS / Docker Web / **Android TV 独立设计**）
> 基线：v2.4.1（33 个 dart 文件，U1-U4 已落地暖阳奶油设计系统）
> 决策建议：**统一品牌基底 + 分平台表现层**；TV 版完全独立设计（10-foot UI）

---

## 一、现状诊断 —— 为什么「丑」

### 1.1 现有 UI 资产（U1-U4 后）

| 层 | 资产 | 状态 |
|---|---|---|
| 设计令牌 | `design_system.dart`（暖阳奶油色板/Spacing/Radii） | ✅ 底子好，但只用了 20% |
| 组件 | CoverImage / PosterCard / HeroCarousel | ⚠️ 无骨架屏、无动效、无焦点层 |
| 主题 | `theme.dart`（浅/深两档） | ⚠️ 深色未打磨，无动效令牌 |
| 页面 | 发现/详情/搜索/播放器/收藏/设置/下载 | ⚠️ 功能全，视觉平 |
| 导航 | 宽屏 Rail / 窄屏底栏 | ⚠️ 无侧栏图标动效、无页面转场 |
| TV | TVFocusable（边框+缩放） | ⚠️ 仅为「能用的手机布局」，不是电视设计 |

### 1.2 病因清单（按影响排序）

1. **没有层次** —— 所有页面都是「白底 + 卡片平铺」，缺 Hero 大图冲击、缺渐变遮罩、缺分组节奏（对比 Netflix 的 Billboard 首屏）。
2. **没有等待体验** —— 网络请求时白屏或转圈，无骨架屏（Shimmer），显得廉价。
3. **没有动效** —— 页面切换生硬、卡片无 hover/按压反馈、轮播切换无视差、无元素共享转场。
4. **播放器太素** —— 控制条是默认 Material 样子，无毛玻璃、无手势区（移动端）、无氛围模式。
5. **TV 版是伪 TV** —— 手机布局 + 焦点边框，字号小、边距小、无安全区、焦点状态不明显，不符合 10-foot UI。
6. **信息密度失控** —— 详情页/设置页全部 ListTile 堆叠，无分组视觉、无大标题层级。

## 二、竞品调研矩阵

### 2.1 国际流媒体

| 竞品 | 设计风格 | 值得抄的交互 |
|---|---|---|
| **Netflix TV（2025 Eclipse 改版）** | 纯黑影院底 + 大 Billboard 首屏 + 顶部水平导航（砍掉左侧栏）| ① 焦点悬停即展开轻量详情浮层（不出行）② 卡片自带上下文角标（#1 / 新季 / 获奖进行中）③ 「响应式推荐」边逛边变 ④ 动画「更利落顺滑」 |
| **Netflix 手机** | 竖版短视频流（TikTok 式）| 竖滑快看片段再决定追剧 |
| **Disney+** | 明亮玻璃拟态、品牌 franchise 分区、轮播 + 行式陈列 | 无 franchise 需求可抄它的「品牌色分区」与行标题+查看全部 |
| **YouTube TV / 移动** | 16:9 卡片 + 静默预览 | 焦点停留 1s 自动静默播放预览（TV 端降选择成本利器） |
| **Apple TV app** | 大字排版、玻璃模糊、克制留白 | 大标题滚动视差、沉浸式详情页（背景即剧照） |

### 2.2 国内平台

| 竞品 | 值得抄的点 |
|---|---|
| **爱奇艺「跳看」** | 横屏播放时屏幕左右边缘上下轻扫 = 上/下跳剧情片段；进度条上的精彩片段标记 |
| **腾讯视频** | 倍速精细到「剧中角色视角」选项；名场面榜单一键跳转 |
| **优酷 AI 速看** | 30s 精华 + 解说，帮助快速决策（对应我们：详情页「先看预告/首集前 3 分钟」） |
| **红果/爱奇艺极速版** | 竖屏沉浸流（上下滑切剧）、免费+金币任务；短剧封面即入口，无文字堆砌 |
| **B 站瀑布流** | 移动端首页双列瀑布流 + 滑动进度条预加载 |

### 2.3 桌面/媒体中心

| 竞品 | 值得抄的点 |
|---|---|
| **Infuse** | 极简侧栏 + 大封面网格 + 剧照当详情页背景（底部渐变压字） |
| **Jellyfin 10.9** | 侧栏 + 快速搜索（Cmd+K 弹层）+ 继续观看行 |
| **IINA/mpv** | 播放器 OSD 半透明毛玻璃 + 快捷键提示浮层 |

### 2.4 TV 10-foot UI 硬规则（Google/Apple 官方 + 行业共识）

1. **字号**：正文 ≥24sp 起（手机 16px 观感），层级精简到 5-6 档。
2. **安全区**：上下 60dp、左右 80dp（≈5% overscan 边距），核心内容绝不贴边。
3. **焦点状态** = 缩放 1.1~1.15 + 辉光/描边 + 阴影，三选二必须明显；全 App 一致。
4. **导航**：D-pad 四向可达、无焦点陷阱；侧栏常驻（顶部栏会随下滚隐藏，键程长）。
5. **陈列栏**：横向行 + 最后一个可见项露出一部分暗示可滚；海报 2:3 为主，16:9/1:1 混排破单调。
6. **焦点图（Spotlight）**：全宽大卡打破陈列栏单调。
7. **色彩**：影院深色为默认，低饱和、禁纯白大面积（夜间刺眼）；亮色只做焦点点缀。
8. **返回键**：永远回到之前的滚动位置，行为可预期。
9. **文字输入最小化**：搜索配历史/热词/语音；能不打字就不打字。

## 三、设计策略总纲

```
┌─────────────────────────────────────────────┐
│           统一品牌基底（Brand Core）          │
│  暖阳奶油 v3：红果粉主强调 + 暖底 + 粉金渐变   │
│  字体/间距/圆角/动效曲线/图标 风格 一套令牌     │
└──────────────┬──────────────┬───────────────┘
               │              │
   ┌───────────▼───┐   ┌──────▼────────┐   ┌──────────────┐
   │ 明亮表现层      │   │ 桌面表现层     │   │ TV 影院层      │
   │ 手机/平板/Docker│   │ Win/Mac/Linux │   │ Android TV    │
   │ (Web)          │   │               │   │ 10-foot 独立  │
   └───────────────┘   └───────────────┘   └──────────────┘
```

- **统一**：品牌色、Logo、圆角语言、动效曲线、图标风格、组件 API。
- **分平台**：
  - **移动端**：明亮暖色为主（延续奶油底），双列瀑布流 + 底部导航 + 手势。
  - **桌面端**：暖底 + 毛玻璃侧栏 + 宽幅 Hero + 悬停预览，更像 Infuse/Apple TV。
  - **TV 端**：**完全独立** —— Cinema Dark（近黑暖黑 #0E0D0B 底）+ 焦点引擎 + 侧栏常驻 + 陈列栏，看齐 Netflix TV。

## 五、关键页面重设计规格

### 5.1 发现页（首页）

**桌面（≥900）**
- 顶部：品牌 Logo + 全局搜索框（居中，`⌘K`/`Ctrl+K` 唤起浮层搜索）+ 外观切换。
- **Cinema Hero**：全宽 16:6 大图轮播（不再是 21:9 小条），底部三段渐变（黑→透明）压标题/年份/评分/**立即播放** 主按钮；右侧竖排指示条（非圆点）。
- 行式陈列栏：`继续观看`（接 drift 进度，横向 16:9 卡 + 底部进度线）→ `热门电影/剧集/综艺/动漫`（2:3 海报，hover 上浮 4px + 海报轻微放大 1.03 + 阴影，1s 后静默加载预览图）。
- 行标题右侧「查看全部 >」→ 网格聚合页。

**移动端**
- 沉浸头部：Hero 轮播通栏（去 AppBar，状态栏透明），下拉返回顶部。
- **双列瀑布流**（B 站式）替代固定网格：封面 2:3、标题、评分角标；触底加载 shimmer。
- 底部导航 5 项：发现 / 直播 / 资源库 / 收藏 / 我的（设置并入「我的」）。

**TV**
- 左侧常驻图标侧栏（56dp 窄轨，聚焦展开 200dp 显示文字；Back 键随时回侧栏）。
- 首屏 = 全宽 **Spotlight 焦点图**（自动轮播 + 焦点即暂停切换 + 大号「播放」胶囊按钮）。
- 下方陈列栏：焦点缩放 1.12 + 金色辉光描边 + 底部标题上浮；最后可见项露 30% 暗示滚动。
- 「继续观看」永远第一行。

### 5.2 详情页

- **沉浸式**：封面图全屏铺底（模糊 + 压暗 40%）→ 内容浮层上移，或共享元素转场（海报无缝放大成头图）。
- 操作区胶囊化：`▶ 立即播放`（渐变主钮）+ `+ 收藏` + `⬇ 下载` + `⇄ 换源`。
- 选集：按季分组 SegmentedButton + 胶囊网格（已看集打勾、当前集高亮描边）。
- 简介：默认 2 行 + 「展开」；演职员横排（有数据后）。

### 5.3 播放器（三端分化）

**移动端（手势优先，看齐爱奇艺）**
- 左半屏双击 = 快退 10s，右半屏双击 = 快进 10s（带涟漪 + 时间气泡）。
- 左边缘竖滑 = 亮度，右边缘竖滑 = 音量（仿 bilibili）。
- 横屏边缘上下滑 = 「跳看」上/下集精彩片段（先做：上下集跳转）。
- 控制条：底部主进度 + 缓冲进度浅色预显 + 手势提示浮层（首次 3s）。

**桌面端**
- OSD 毛玻璃（BackdropFilter blur 20 + 黑 40%）胶囊控制条，悬停常驻、播放中 3s 隐藏。
- 快捷键全套：Space 播放/暂停、←→ 5s、↑↓ 音量、F 全屏、Esc 退出、0-9 跳百分比、[, ] 倍速。
- 「氛围模式」：暂停 3s 后自动虚化当前帧做背景 + 剧名 Display 字（可关）。

**TV 端**
- 全屏播放，OK 键呼出 OSD；焦点默认在「进度条 scrubber」上，左右 = ±30s，下 = 展开选集行，上 = 控制按钮排。
- OSD 按钮 ≥64dp 焦点格；倍速/选集/换源以底部横向陈列栏形式滑入（不弹全屏对话框）。
- 数字键直跳百分比；长按 OK = 倍速 2x（松开恢复）。

### 5.4 收藏/历史

- 桌面：侧栏二级页，顶部「继续观看」行 + 封面网格；编辑模式多选已有，补批量操作浮条（底部滑入）。
- 移动：沿用双列网格 + 长按多选，选中有弹缩放动画。

### 5.5 设置中心

- 分组卡改「图标彩色底 + 标题 + 当前值」行样式（对齐 macOS 系统设置质感）。
- 外观选择器：三张实时预览缩略卡（浅/深/跟随），不是文字列表。
- 关于页：加 Logo + 渐变横幅 + 版本徽章。

## 六、TV 版独立设计系统（`tv/` 模块，不与手机共用页面）

### 6.1 架构

```
lib/features/tv/
  tv_theme.dart        // Cinema Dark 令牌 + safeArea 常量
  tv_focus.dart        // TvFocusable v2：scale 1.12 + 金辉光 + 声音可选
  tv_scaffold.dart     // 常驻窄轨侧栏 + 内容区 + 安全区包装
  tv_shelf.dart        // 陈列栏（横向行 + 焦点管理 + 末项露出）
  tv_spotlight.dart    // 全宽焦点图
  tv_keyboard.dart     // 大格屏幕键盘（网格 10 列）
  tv_player_osd.dart   // TV 播放器 OSD
  tv_pages/…           // tv_home / tv_detail / tv_search / tv_live
```

### 6.2 交互规格

| 项 | 规格 |
|---|---|
| 初始焦点 | 每页进页必落焦点：首页=Spotlight 播放钮，详情=立即播放 |
| 焦点样式 | scale 1.12（spring 250ms）+ 2dp 金描边 + 12dp 辉光 + 邻居项压暗 80% 透明度 |
| Back 键 | 播放中=呼出/隐藏 OSD；OSD 开=关 OSD；页面=返回并恢复滚动位置 |
| 长按 OK | 播放中 2x 倍速 |
| 菜单键 | 直达侧栏 |
| 焦点记忆 | 从陈列栏第 5 项进详情，返回焦点必须还在第 5 项 |
| 防焦点陷阱 | 陈列栏 ↔ 侧栏左右双向可达；OSD/弹层关闭后焦点归位 |
| overscan | 全局 safeArea 包装：上下 60dp 左右 80dp |
| 性能 | 焦点缩放用 Transform（不走 rebuild）；海报用 cached_network_image 内存缓存调优 |

## 九、实施路线图

### S1 · 视觉地基（≈对齐「不丑」）
- 令牌 v3（色/字/动效）+ Shimmer + EmptyState + 页面转场 + 深色走查
- 发现页桌面版 Cinema Hero + 行式陈列栏；移动端瀑布流
- **验收**：首屏有层次、加载有骨架、切换有动效

### S2 · 播放器与详情
- 详情页沉浸式 + 共享元素转场；播放器三端分化（移动手势 / 桌面 OSD+快捷键 / 氛围模式）
- **验收**：详情「像 Netflix」，播放器三端各有原生质感

### S3 · TV 独立版
- tv/ 八件套 + 四个 TV 页面 + TV 播放器 OSD + 遥控键位表
- **验收**：遥控器全流程无死角（侧栏↔陈列栏↔详情↔播放），焦点样式全站一致，安全区合规

### 风险与注意
- Flutter 3.35 macOS 黑屏教训：任何启动期 IO 必须 try/catch（网关事件已修，新代码沿用）。
- TV 设备性能弱：焦点动画用 Transform、避免整页 rebuild；图片缓存上限调低。
- 瀑布流用 `flutter_staggered_grid_view`（新增依赖，体积小）。
- 每期照旧：`flutter analyze 0 issues` + `flutter build web` + 真机抽查，TV 需模拟器+遥控器实测。
